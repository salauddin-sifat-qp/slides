The update

State of Wick UI —
from the devs

Wick UI v2.19.0 · live now

v2 is live.

  • Component customization (Tailwind, wu-* overrides) is now fully deprecated — request changes via #wick-ui-lib instead
  • Every package — lib, editor, i18n, icon — shares one version number, always in sync

(Also — some portal conflicts from the library changes. Flag them in #wick-ui-lib if you hit one.)

Mark your calendar

React 18 support
sunsets end of 2026.

React 19 is done and live. Still on React 18? You have runway — but the clock is running.

Where this is headed

v2 is the
migration phase.

  • Base UI, replacing Radix
  • CSS Modules, replacing Tailwind
  • Consistent UI across form components and beyond — roundness, spacing, unified
  • Fewer third-party dependencies, more familiar APIs
  • Small, low-impact breaking changes now and then
  • Building toward a rock-solid v3
Translate this

What this means
for you.

  • Fewer dependencies = fewer surprise bugs, faster fixes
  • Custom styling now goes through a request, not a code override — more consistent UI across every team
  • A few small bumps now, in exchange for a stable v3 later
