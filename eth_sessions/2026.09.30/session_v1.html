Live

Stage. Commit. PR. Check.

ruby ❯ /commit

ruby ❯ /pr

/pr-check house style

One line. What, why, fix.
No essays.

Migration has no down() — rollback on regional DBs will fail. Fix: add down() dropping answer_text.
CI e2e failed on ENOTFOUND mysql-test — runner infra, not your code. Fix: re-run the job.

Posted as inline review comments. Never approves, never blocks. It advises.

Definition 1 of 3

Embedding: meaning, as numbers.

photosynthesis chlorophyll sunlight invoice refund
"chlorophyll" → [0.12, -0.83, 0.44, …]
"invoice" → [-0.71, 0.09, -0.22, …]

Similar meaning, nearby numbers. "Chlorophyll" lives next to "sunlight", far from "refund".

Definition 2 of 3

Vector DB: Ctrl+F for meaning.

StoresEvery chunk of the book, as an embedding
FindsThe chunks closest in meaning to your question, in milliseconds
EmbeddedLives inside the app as a file. No extra server to babysit.

Confession #4

The system prompt matters
more than you think.

Same model. Very different engineer.
What the model actually reads

Three layers.
Most people only touch one.

System promptHow the agent behaves: rules, discipline, output stylethis talk
CLAUDE.mdWhat the project is: stack, commands, conventionscontext
Your messageWhat you want right nowtask
Default vs tuned

Claude Code's prompt is
written for everyone.

Stock Claude Code

  • Generic software-engineering rules
  • Tuned for the average user
  • Tends to add "helpful" extras

My 176-line system prompt

  • Read before you edit. Evidence over assumption.
  • Smallest correct change. No drive-by refactors.
  • Verify once, at the end. Then stop.
  • Terse output. Three lines, not three paragraphs.
